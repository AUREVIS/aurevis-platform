# AUREVIS V2.4 — Orders and Sales

## 1. Supabase

Supabase Dashboard-ում բացել **SQL Editor → New query**, պատճենել և մեկ անգամ աշխատեցնել՝

`supabase/AUREVIS_V2_4_ORDER_SALES.sql`

Այս քայլը պահպանում է առկա հաճախորդներն ու պատվերները և ավելացնում է՝

- պատվերի ապրանքների առանձին պահպանում,
- կարգավիճակների պատմություն,
- ավարտված վաճառքների հաշվարկ,
- 5% cashback-ի միանվագ հաշվարկ,
- Admin sales dashboard-ի տվյալներ։

## 3. Workflow

Admin-ում պատվերի փուլերն են՝ New → Confirmed → Preparing → Delivery → Completed։

`Completed` կամ `Cancelled` պատվերը վերջնական է և այլևս չի փոխվում։ Ավարտված պատվերը՝

- հաճախորդի մոտ տեղափոխվում է Order History,
- Admin-ում տեղափոխվում է Sales History,
- մտնում է օրվա, ամսվա և ընդհանուր վաճառքի մեջ,
- հաճախորդի wallet-ին մեկ անգամ ավելացնում է 5% cashback։
